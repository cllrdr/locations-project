# INFO 
Это проект locations-project. Проект на golang - Веб-приложение, которое позволяет просматривать локации и выбирать понравившиеся. 
Далее локации попадают в "корзину" игрока, а из них рандом будет выбирать одну локацию, на которую попадет игрок.
Другие используемые компоненты можно посмотреть в docker-compose.yml
